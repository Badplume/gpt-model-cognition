# 入门型 AI 通用节省计划与 Model Delegator

官方依据（查询于 2026-10-16）：https://help.aliyun.com/zh/model-studio/savings-plan-and-resource-package

该计划通过普通百炼 API Key 和同地域按量接口自动抵扣；当前插件提供北京地域 Qwen 接入。独立 DeepSeek / BigModel / Moonshot 账户调用不消耗阿里云额度。仅阿里直供模型符合通用抵扣范围，三方直供除外；低于 1000 元月承诺档位不抵扣 kimi-k3。入门档主要优惠来自购买额度时的优惠，不代表每次 Token 单价永久打折。动态月额度到期清零，超额或到期后转按量。具体账户额度、地域、有效期须在用户控制台核对。

建议：用已获额度的 Qwen Flash 处理文字摘要、字段提取、分类和翻译；用 Qwen Plus 进行代码或方案复核，由 GPT 综合。先用小任务查看百炼账单抵扣明细，再增加频率。模型按官方原价参与插件预算，避免未验证优惠导致超支；可根据剩余月额度/剩余天数调整人民币日预算。当前插件处理文本咨询，未声称支持语音、图像或知识库服务。
